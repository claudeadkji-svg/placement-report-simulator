# 게재보고 시뮬레이터 (정적 사이트)

광고 소재를 상품별 템플릿에 합성해 실제 게재면과 동일한 캡처 이미지를 만드는 웹 도구.
서버 없이 브라우저에서 동작하며 GitHub Pages로 호스팅됩니다.

## 사용법
1. 접속 후 팀 비밀번호 입력 (초기: `nas2026`, `docs/index.html`의 HASH로 변경)
2. **상품 선택** — 유튜브 VVC / VRC / Run of Shorts, 각각 MO·PC 버전 제공
3. **소재 입력** — 이미지 업로드, 영상 업로드 후 슬라이더로 장면 선택, 또는 유튜브 URL 입력
4. **요소별 설정** — 상태바 시간·신호·배터리(MO), 검색어, 제목/부제/스폰서, CTA 문구·색, (쇼츠)좋아요·댓글·공유 등 모두 개별 조정
5. **고화질 PNG 다운로드** — 미리보기 그대로 3배 해상도로 저장 → 게재보고 덱에 삽입

## 유튜브 URL 소재
"유튜브 URL" 탭에 watch / youtu.be / shorts 주소를 넣으면 영상의 최고화질 대표 썸네일을
가져와 소재로 적용하고, 제목·채널명을 자동 입력합니다(체크 해제 가능).
썸네일은 i.ytimg.com에서 직접 가져오며(CORS 허용), 실패 시 images.weserv.nl 프록시로 재시도.
메타데이터는 noembed.com 사용. 정적 사이트라 임의 장면 추출은 불가 —
특정 장면이 필요하면 영상을 파일로 저장해 "영상(프레임)" 탭에서 선택하세요.

## 구조
- `docs/index.html` — 비밀번호 게이트 + 레이아웃
- `docs/app.js` — 템플릿 렌더 + 요소별 컨트롤 + 영상 프레임 선택 + PNG 추출(html2canvas)
- `docs/style.css` — 컨트롤 + 템플릿 스타일
- `docs/lib/html2canvas.min.js` — 화면→PNG 변환(로컬 번들)

## 템플릿 추가
`app.js`의 `DEF`/`CTRL`에 상품 설정·컨트롤을 추가하고, 렌더 함수(renderInfeed/renderShorts류)를 확장.
다음 확장 예정: 네이버(브랜드검색·GFA·치지직), 카카오(비즈보드), SOOP, PC 지면.
