1. 이 도구는 무엇인가요?

게재보고를 만들 때 실제 화면을 캡처할 수 없는 지면(라이브가 끝난 캠페인, 타기팅 때문에 내 계정에서 안 보이는 지면 등)을 채우기 위한 도구입니다. 광고 소재를 넣고 상품을 고르면 실제 유튜브 게재면과 동일한 레이아웃으로 합성한 고화질(1080px) 이미지를 만들어 줍니다.

⚠️ 이 도구로 만든 이미지는 시뮬레이션입니다. 실제 캡처가 가능한 지면은 반드시 실제 캡처를 사용하고, 시뮬레이션 이미지 사용은 팀 공유 기준을 따라 주세요.

2. 접속과 로그인

주소: https://claudeadkji-svg.github.io/placement-report-simulator/

  • 1비밀번호 입력칸 — 팀 공용 비밀번호를 입력합니다. 비밀번호는 팀 리더에게 문의하세요.
  • 2접속 버튼 — 클릭(또는 Enter)하면 바로 작업 화면이 열립니다.

3. 전체 프로세스 한눈에 보기 (4단계)

화면은 왼쪽 = 조작, 오른쪽 = 실시간 미리보기로 나뉩니다. 왼쪽에서 무엇이든 바꾸면 오른쪽에 즉시 반영됩니다.

번호영역하는 일
11. 상품 선택드롭다운에서 게재 지면을 고릅니다. 모바일(MO) 4종 + 데스크톱(PC) 3종. 상품을 바꾸면 미리보기와 아래 설정 항목이 그 지면에 맞게 통째로 바뀝니다.
22. 소재 입력탭 3개(이미지 / 영상(프레임) / 유튜브 URL) 중 하나로 광고 소재를 넣습니다. → 4장에서 자세히.
33. 요소별 설정시간·배터리·검색어·제목·CTA 색까지 화면의 모든 요소를 개별 조정합니다. → 6장에서 자세히.
4고화질 PNG 다운로드완성되면 클릭. 미리보기 그대로 3배 해상도(가로 1080px)로 저장됩니다.
5실시간 미리보기지금 저장하면 나올 결과물 그대로입니다. 빗금 영역("여기에 광고 소재")에 소재가 합성됩니다.
가장 짧은 사용 흐름:
  1. 1상품 선택 (예: 유튜브 VVC — 검색 인피드)
  2. 2소재 입력 (예: 이미지 탭에서 소재 파일 업로드)
  3. 3광고주 이름·제목·CTA 문구만 캠페인에 맞게 수정
  4. 4고화질 PNG 다운로드 → 게재보고 덱에 삽입

4. 소재 넣는 3가지 방법

방법 A — 이미지 파일 업로드 (가장 간단)

"이미지" 탭에서 파일 선택을 누르고 소재 이미지(JPG/PNG)를 고르면 즉시 미리보기에 합성됩니다. 소재 시안이나 스틸컷이 있을 때 사용하세요.

방법 B — 영상 파일에서 원하는 장면 뽑기

  • 1영상 파일 업로드 — "영상(프레임)" 탭에서 소재 영상 파일(MP4 등)을 선택합니다.
  • 2장면 선택 슬라이더 — 업로드가 끝나면 슬라이더가 나타납니다. 좌우로 드래그하면 위에 초 단위 위치가 표시되고, 그 시점의 프레임이 바로 소재로 적용됩니다. 브랜드 로고가 크게 나오는 장면 등 원하는 컷에서 멈추면 됩니다.
💡 화질이 생명입니다. 영상 소재는 반드시 최대 해상도(1080p 이상) 원본 파일을 사용하세요. 저화질 파일로 만들면 게재보고 결과물도 흐릿해집니다.

방법 C — 유튜브 URL로 가져오기

  • 1URL 입력 — "유튜브 URL" 탭에 영상 주소를 붙여넣습니다. youtube.com/watch?v=…, youtu.be/…, /shorts/… 모두 인식합니다.
  • 2제목·채널명 자동 입력 — 체크해 두면(기본값) 영상 제목과 채널명이 아래 "요소별 설정"의 제목·스폰서명 칸에 자동으로 채워집니다.
  • 3소재 가져오기 — 클릭하면 그 영상의 최고화질 대표 썸네일을 받아 소재로 적용합니다. 버튼 아래에 "적용 완료" 상태가 표시됩니다.
💡 URL 방식은 대표 썸네일만 가져옵니다. 영상 중간의 특정 장면이 필요하면 방법 B(영상 파일 업로드)를 사용하세요.

5. 신규 상품: 유튜브 마스트헤드 (홈피드 최상단 · MO)

이번 업데이트로 유튜브 마스트헤드 템플릿이 추가되어, 모바일 지면은 총 4종이 되었습니다. 마스트헤드는 유튜브 앱 홈 화면 최상단에 노출되는 대형 영상 지면으로, 라이브 당일 하루만 게재되는 경우가 많아 사후 캡처가 특히 어려운 상품입니다.

  • 1상품 선택에서 "유튜브 마스트헤드 — 홈피드 최상단 (MO)"를 고릅니다.
  • 2미리보기 — 유튜브 홈 상단바(로고·아이콘), 카테고리 칩, 소재 영역, 음소거 버튼, "광고" 라벨, CTA 버튼, 아래로 이어지는 오가닉 콘텐츠까지 실제 마스트헤드 구조 그대로 재현됩니다.

마스트헤드 전용 설정 항목:

그룹항목설명
홈 상단카테고리 칩"전체 · 음악 · 게임…" 칩 줄 표시/숨김
영상음소거 버튼실제 마스트헤드처럼 우하단 음소거 아이콘 표시/숨김
영상재생시간입력하면 우하단에 시간 배지 표시, 비우면 숨김(기본)
광고 정보"광고" 라벨채널명 앞의 광고 표기 켜기/끄기
광고 정보하단 오가닉마스트헤드 아래로 살짝 보이는 다음 동영상 영역 표시/숨김

6. 요소별 설정 — 무엇을 바꿀 수 있나

"3. 요소별 설정"에는 선택한 상품의 화면 요소가 그룹별로 나열됩니다. 입력하는 즉시 미리보기에 반영됩니다.

그룹대표 항목이렇게 쓰세요
상태바 (MO)시간, 신호 강도, 와이파이, 배터리 %캡처처럼 자연스럽게 — 보고서의 다른 실캡처와 시간대를 맞추면 좋습니다.
검색·영상검색어, 필터칩(VRC), 재생시간, 진행바검색어는 실제 캠페인 키워드로. VRC 상품은 필터칩이 자동으로 켜집니다.
광고 정보아바타 글자·색, 제목, 부제, 스폰서명, "스폰서/광고" 라벨광고주 브랜드명과 실제 집행 문구를 입력하세요. 유튜브 URL로 소재를 가져왔다면 자동으로 채워져 있습니다.
CTA버튼 문구, 버튼 색버튼 색은 색상 선택기를 눌러 소재 톤에 맞춥니다.
Shorts 전용좋아요/댓글 수, 광고 배지, 하단 내비게이션숫자는 자연스러운 값으로 자유 입력.

7. 이미지 저장과 게재보고 활용

  1. 미리보기가 원하는 모습이 되면 왼쪽 아래 고화질 PNG 다운로드를 클릭합니다.
  2. 버튼이 잠시 "내보내는 중…"으로 바뀐 뒤, 게재면_상품명.png 파일이 다운로드됩니다. 미리보기의 3배 해상도(가로 1080px)라 보고서 삽입 시에도 선명합니다.
  3. PPT 게재보고 덱의 해당 지면 슬롯에 붙여넣으면 끝입니다.

8. 주의사항 · FAQ

Q. 소재 가져오기가 "가져오기 실패"라고 나와요

비공개/삭제된 영상이거나 썸네일이 없는 영상입니다. 소재 파일(이미지·영상)을 직접 업로드하는 방법을 사용하세요.

Q. 세로형(Shorts) 지면인데 가로 썸네일이 들어가요

유튜브 URL 방식은 세로 썸네일을 우선 탐색하지만 영상에 따라 없을 수 있습니다. 이 경우 "영상(프레임)" 탭에서 세로 원본(1080×1920)을 올려 장면을 선택하는 것이 가장 확실합니다.

Q. 새 지면(네이버·카카오 등)이 필요해요

템플릿은 계속 확장 예정입니다. 필요한 지면과 실제 캡처 샘플을 관리 담당자에게 전달해 주세요.

Q. 화면이 예전 그대로예요 (새 상품이 안 보여요)

브라우저 캐시 때문일 수 있습니다. Ctrl+F5(강력 새로고침)를 눌러 주세요.
